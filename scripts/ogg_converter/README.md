# ogg_converter Xiaozhi AI OGG Batch Converter

This script is an OGG batch conversion tool that supports converting input audio files into OGG format usable by Xiaozhi.
Implemented based on the Python third-party library `ffmpeg-python`.
Supports mutual conversion between OGG and other audio formats, loudness adjustment, and other functions.

# Create and activate virtual environment

```bash
# Create virtual environment
python -m venv venv
# Activate virtual environment
source venv/bin/activate # Mac/Linux
venc\Scripts\\activate # Windows
```

# Install dependencies

Please execute in the virtual environment

```bash
pip install ffmpeg-python
```

# Run script
```bash
python ogg_converter.py
```

# ogg_converter Công cụ chuyển đổi hàng loạt OGG cho Xiaozhi AI

Script này là một công cụ chuyển đổi hàng loạt OGG, hỗ trợ chuyển đổi các tệp âm thanh đầu vào sang định dạng OGG mà Xiaozhi có thể sử dụng.
Được triển khai dựa trên thư viện bên thứ ba `ffmpeg-python` của Python.
Hỗ trợ chuyển đổi qua lại giữa OGG và các định dạng âm thanh khác, điều chỉnh độ lớn và các chức năng khác.
